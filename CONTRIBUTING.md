# Contributing

Please:

1. Open an issue first, before sending a pull request.
2. Keep it from buying: changes that add to cart or check out without an explicit ask, or message anyone besides the owner, won't be merged.
3. Use fictional people, ZIPs, and addresses in tests, issues, and examples.
4. If you change instructions or a skill, run the scenarios in `tests/scenarios.md` and add a CHANGELOG entry.
