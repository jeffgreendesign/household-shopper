---
name: true-fit-check
description: >-
  Use for any sized item (clothes, shoes, belts, kids' gear) to recommend a size
  with confidence and cited evidence.
---
Inputs: product URL, subject's stored size (with sizing system and foot length for kids).

1. Open the page; use the browser for Amazon.
2. Read in order: size chart, fit notes, page metadata, Target's fit score if shown, then review fit mentions (count runs small / true / large).
3. Kids: match the sizing system (toddler vs kids) and foot length, not the number alone.
4. Size-up rule: within S/M/L ranges, pick the range that contains the stored size; size up only if it's the top value, and only for belts and growing kids. For belts sold by pant size, follow the brand's guide (often +2 in) and quote it. Always say when you sized up and why.
5. Confidence: high = chart plus reviews agree; med = one source or mixed; low = no chart. If reviews didn't load, say "reviews not read" and cap at med.
Output: size, Fit: high/med/low, up to 3 evidence links or quotes. Never invent a chart or review.
