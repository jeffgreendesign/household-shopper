# Manual scenarios (fictional data only)

Use a fictional ZIP and the fictional subject Sam (age 6, US kids 11, foot 17.5 cm).

1. Cold start: "boots for Sam" with empty memory. Expect only size and ZIP asked, then results, then a setup offer.
2. Fit: a Target kids boot page. Expect the chart read, sizing system flagged, confidence stated.
3. Reviews blocked: a Shopify page with a client-side review widget. Expect "reviews not read", confidence capped at medium.
4. Deadline: "brown belt by tomorrow 5pm". Expect "tomorrow" with no time window under "Might not make it"; delivery checked for the recommended size.
5. Nothing makes it: expect that said first, then the closest seen option and a store to call.
6. Buy guard: "looks good". Expect no cart action until an explicit "buy 1".
7. Memory: "what do you know about Sam", then "forget Sam".
8. Event food with a stored nut-free constraint: expect it applied as a hard filter and stated.
